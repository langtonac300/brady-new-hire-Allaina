# The project ladder

The actual work of your first 90 days: a set of projects that start at about an hour each
and grow to week-long by the end.

**The length is part of the training.** A week-long project needs skills a one-hour project
doesn't — scoping, pacing yourself, knowing when to ask. So the ladder builds both the
subject matter and the ability to work at that size.

---

## How each project works

| | |
|---|---|
| **Time box** | If a one-hour project runs to three, it was scoped wrong. Say so — that's useful feedback, not a failure |
| **Safety tier** | *Read-only* → *reversible and reviewed* → *independent within guardrails.* It rises as you go |
| **Deliverable** | Every project leaves something behind — a list, a doc, a diagram. Put it in `04-my-work/projects/` |
| **Paired or solo** | Some you'll do with Alex, most on your own with a short readout |

## The mechanic that does most of the work: predict, then compare

On anything with a right answer, **you make your call first, then see the answer, then
explain the difference.**

That order matters. Watching someone else be right teaches almost nothing; being wrong and
then finding out why is what actually sticks. Expect to be wrong a lot early on — the
"explain the difference" step is where the learning is, not the score.

---

## Roughly what's coming

| Weeks | Tier | Looks like |
|:-----:|------|-----------|
| 1–4 | **One-hour projects, read-only** | Account tours, sorting exercises, "where did this number come from" drills |
| 4–7 | **Half-day projects, reviewed** | Search-terms reviews, your first negative-keyword build, your first live change (on Mecco) |
| 7–10 | **One-to-two-day projects** | Real diagnosis work — conversion tracking, process gaps, budget recommendations |
| 11–13 | **Week-long capstones** | End-to-end pieces of work you own and present |

Alongside those, two threads run continuously: a **tools thread** (the dashboards, Power BI,
BigQuery, the weekly huddle) and an **AI thread** (using LLMs for actual workflows rather
than as a question box).

## The individual projects

Alex will add these as you reach them, so you're not looking at 40 projects on day one.
Each arrives as its own file in this folder with the brief, what you need, and what "good"
looks like.

If you want to see further ahead than you've been given, just ask.
